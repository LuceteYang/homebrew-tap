# homebrew-tap

[PikaTokenBar](https://github.com/LuceteYang/PikaTokenBar) 설치용 Homebrew tap.

```bash
brew install --cask LuceteYang/tap/pika-token-bar
```

업데이트는 `brew upgrade --cask pika-token-bar`.

PikaTokenBar 는 [PokeTokenBar](https://github.com/chattymin/PokeTokenBar) 의 포크로, 1세대(#1–151) 포켓몬만 등장합니다.
